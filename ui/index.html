Open a project

Paste the full path to a local folder. It's copied into the agent's sandboxed workspace — the original folder is never modified, and the agent can only ever touch files inside the sandbox.

Command-line access

Everything this UI does is also available from a terminal, using the same running agent server. 

python cli.py --task "add input validation" --project my-app
python cli.py --task "run the test suite" --project my-app --allow-commands
python cli.py --list-projects
python cli.py --import "C:\path\to\folder" --name my-app
python cli.py --list-models
python cli.py --model "llama3.2:latest" --backend ollama
python cli.py --download-zip --project my-app

Settings

Model

Choose the built-in portable model, or (optional) any model Ollama reports installed — local or cloud. Ollama is entirely opt-in; the portable flow keeps working either way.

Streaming & logging
Verbose event streaming
Show every tool call, command, and reasoning step live in the chat as the agent works, not just the final answer.
Testing phase
Let the tester role run tests (pytest/npm/etc.) after changes. Turning this off also unchecks "Allow commands" for new runs.
